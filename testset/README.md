# Test set (not included)

The real test set is not published: its gold answers and review notes quote copyrighted course material.
`ragtraining/eval/retrieval.py` (`load_testset`) and `ragtraining/eval/manual.py` read these files:

- **`synthetic.jsonl`**: one JSON object per line, generated by Claude from a sampled chunk
  (`ragtraining/eval/testset.py`). Fields: `usable` (generator's own check), `question`, `answer` (reference answer),
  `difficulty`, `gold_chunk_id`, `path`, `course`, `doc_type`, `page_start`, `page_end`, `section`, `source`.
- **`synthetic_review.md`**: a human spot-check, one verdict per item (`OK` / `BAD`); BAD items are dropped.
- **`manual_questions.md`**: your own questions, one block each: the question exactly as you would type it,
  a `kind` (`answerable`, `vague`, `not_covered`), the gold sources as `file p.X-Y` or `file §Section`, and key points.
